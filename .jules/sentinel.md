## 2025-02-24 - [CRITICAL] Prevent Path Traversal in TinaCMS Filename Creation
**Vulnerability:** TinaCMS `slugify` function was using `github-slugger`'s `slug` method to generate filenames for new blog posts. While `github-slugger` strips many special characters, it may not adequately prevent all path traversal vectors if input is crafted maliciously, potentially allowing an attacker to write files outside the intended content directory.
**Learning:** `tina/config.ts` was bypassing the project's internal `safeFilename` utility (which explicitly strips `/`, `\`, and `..` *after* slugification) and was directly using `github-slugger` for generating actual file paths. This breaks the defense-in-depth strategy established for file generation operations.
**Prevention:** Always enforce the use of the `safeFilename` wrapper in `tina/config.ts`'s `slugify` callback, ensuring all generated filenames are strictly sanitized against path traversal characters before file system creation.
